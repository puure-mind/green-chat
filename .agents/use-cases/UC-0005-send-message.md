# UC-0005-send-message

## Actor
- Пользователь

## Goal
- Я как пользователь хочу иметь возможность отправить новое сообщение в чат с другим пользователем

## Preconditions
- Диалог с другим пользователем существует
- Текущий пользователь участник чата

## Trigger
- пользователь ввел сообщение пытается его отправить

## Happy Path
1. Система валидирует сообщение
2. Система отображает сообщение в чате
3. Сервер принял сообщение

## Failures

### Failure 1
- Сообщение не прошло валидацию на HP1
1. При клике на кнопку для отправки сообщение не отправляется
2. Система показывает пользователю, что сообщение не прошло валидацию
3. Поле ввода сообщения не очищается и пользователь может попытаться снова

### Failure 2
- Сервер отклонил сообщение на HP3
1. Поле ввода с сообщением очищается
2. Сообщение появляется в чате со статусом failed, Пользователь может попытаться отправить его снова (optimistic update)
3. Пользователь может написать и отправить новое сообщение

## Postconditions
- Текущий пользователь видит отправленное сообщение в чате
- Пользователь может отправить новое сообщение

## Business rules
- Пользователь может отправлять сообщения только в чаты в которых он является участником
- Сообщения которые не удалось отправить не удаляются и имеют статус failed
- Порядок сообщений должен соответствовать порюдку их отправки
