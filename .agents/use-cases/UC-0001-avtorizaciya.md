# UC-0001-Авторизация

## Actor
- Пользователь

## Goal
- Я как пользователь хочу подтвердить свою личность чтобы получить доступ к своей учетной записи

## Preconditions
- Пользователь не авторизован

## Trigger
- Открытие приложения

## Happy Path
1. Пользователь вводит данные: idInstance, apiTokenInstance
2. Система проверяет наличие пользователя
3. Система сохраняет токен авторизации для дальнейшего использования
4. Пользователь получает доступ к основной части приложения

## Failures

### Failure 1
- F1: Пользователя не существует на HP2
1. Авторизация не запускается
2. Система сообщает пользователю, что такого пользователя не существует
3. Поля ввода не очищаются
4. Пользователь может изменить данные и попытаться авторизиоваться снова

Postconditions:
- Авторизация не прошла
- Поля не очищаются

## Postconditions
- Пользователь получил доступ к основной части приложения
