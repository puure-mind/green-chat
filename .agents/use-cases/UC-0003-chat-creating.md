# UC-0003-chat-creating

## Actor
- Пользователь

## Goal
- Я как пользователь хочу иметь возможность создать диалог с другим пользователем, чтобы начать обмениваться сообщениями

## Preconditions
- Целевой пользователь существует и не заблокирован
- С целевым пользователем не существует чат

## Trigger
- Пользователь создает диалог с целевым пользователем

## Happy Path
1. Система создает новый чат
2. Система отображает пользователю созданный пустой чат

## Failures

### Failure 1
- Система не смогла создать новый чат на HP1 (Happy Path 1)
1. Система показывает пользователю, что не удалось начать диалог
2. Состояние системы не меняется

## Postconditions
1. Текущий пользователь видит пустой чат с целевым пользователем
2. Чат доступен пользователю и отображается в списке чатов

- нет
