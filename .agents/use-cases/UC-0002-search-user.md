# UC-0002-create-chat-by-phone

## Actor
- Пользователь

## Goal
- Я как пользователь хочу создать чат по номеру телефона чтобы начать диалог

## Preconditions
- Текущий пользователь авторизован

## Trigger
- Пользователь ввел номер телефона другого пользователя и нажал "Создать чат"

## Happy Path
1. Система валидирует номер телефона
2. Система очищает предыдущую ошибку, если она была
3. Система создает чат по введенному номеру телефона без проверки регистрации пользователя
4. Система отображает созданный чат в списке чатов
5. Текущий пользователь может открыть созданный чат

## Failures

### Failure 1
- Валидация номера телефона не прошла
1. Система сообщает пользователю об ошибке
2. Пользователь может изменить данные и повторить попытку

### Failure 2
- Пользователь ввел свой номер телефона
1. Система сообщает пользователю об ошибке
2. Система не создает чат с самим собой

## Postconditions
- Текущий пользователь видит созданный чат в списке чатов и может открыть его

## Business rules
- Пользователь не может начать диалог сам с собой
- номер уникален, один номер - один пользователь
- номер телефона - публичные данные
- система не проверяет зарегистрирован ли пользователь по введенному номеру
- повторное создание чата с тем же номером открывает существующий чат вместо создания дубля

## Open questions
- Какой экран должен открываться после создания чата: сразу область диалога или только выделение в списке?
