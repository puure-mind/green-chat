# UC-0002-search-user

## Actor
- Пользователь

## Goal
- Я как пользователь хочу найти другого пользователя чтобы начать с ним диалог

## Preconditions
- Текущий пользователь авторизован

## Trigger
- Пользователь ввел номер телефона другого пользователя и запустил поиск

## Happy Path
1. Система валидирует номер телефона
2. Система очищает предыдущий результат поиска, если он был
3. Система выполняет поиск зарегистрированного пользователя по номеру телефона
4. Система отображает в списке поиска профиль найденного пользователя
5. Текущий пользователь может начать диалог с найденным пользователем

## Failures

### Failure 1
- Пользователь по номеру телефона не найден
1. Система показывает сообщение - ничего не найдено
2. Состояние системы не меняется

### Failure 2
- Валидация номера телефона не прошла
1. Система сообщает пользователю об ошибке
2. Пользователь может изменить данные и повторить попытку

### Failure 3
- Пользователь ввел свой номер телефона
1. Пользователь видит свой профиль и может посмотреть его публиччную информацию, но не может начать диалог

## Postconditions
- Текущий пользователь видит в списке поиска профиль найденного пользователья и может начать с ним чат

## Business rules
- Пользователь не может начать диалог сам с собой
- Пользователь может увидеть только публичную информацию другого пользователя
- для начала диалога пользователь должен явно выбрать "начать диалог"
- номер уникален, один номер - один пользователь
- номер телефона - публичные данные
- для поиска доступны только активные зарегистрированные пользователи
