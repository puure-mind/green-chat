# UC-0004-open-existing-chat

## Actor
- Пользователь

## Goal
- Я как пользователь хочу иметь возможность открыть и просматривать существующие чаты, чтобы читать историю сообщений

## Preconditions
- чат существует
- у текущего пользователя есть доступ к выбранному чату

## Trigger
- Пользователь выбрал чат

## Happy Path
1. Система получает историю сообщений
2. Система отображает пользователю чат с сообщениями

## Failures

### Failure 1
- Система не смогла получить историю сообщений на HP1
1. чат открыт
2. в чате нет сообщений
3. Пользователь может написать новое сообщение

## Postconditions
- Текущий пользователь видит чат с целевым пользователем
- Пользователь видит историю сообщений

## Business rules
- Сообщения сортируются сверху вниз от более старых к новым
- Пользователь видит только доступные ему чаты, в которых он участвует

- Как запрашивать более старые сообщения?
