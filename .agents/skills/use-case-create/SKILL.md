# Instructions

1. Read the template @/assets/template.md.
2. For each section and placeholder, ask the user to write a response.
3. Write the user’s response in the section.
4. Save the file in @.agents/use-cases in the format [UC-<number>-case-name].md.

## description
- UC-number is autoincrement in format UC-xxxx integers value

## Definition of done
1. A new file has been created based on the user’s responses.
2. The new file contains the information received from the user.

## Never
- Don’t overthink it and don’t make things up.
- Don’t deviate from the pattern.
